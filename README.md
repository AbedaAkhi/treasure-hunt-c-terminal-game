# Treasure Hunt — Unix Terminal Game (C)

**Unit:** COMP1000 — Unix and C Programming  
**Institution:** Curtin University, Miri (Malaysia)  
**Period:** Semester 2, 2024  
**Project type:** Individual university coursework (documentation-only case study)

## Overview

Treasure Hunt is a terminal-based grid game developed as part of an introductory Unix and C programming assignment. The player navigates a map with keyboard commands, avoids walls and a moving snake, and attempts to reach treasure.

This repository documents the submitted work and development process **without distributing the assessed source code**.

## Work evidenced in the supplied materials

- Developed C code for the game loop, player movement, and basic win/lose handling.
- Read and rendered a grid map using text-file input and a two-dimensional array.
- Applied keyboard controls and terminal display updates for an interactive game.
- Used a random-number utility for snake movement and a terminal input utility for character input.
- Organised code into multiple C source/header modules and a Makefile.
- Explored an optional DARK display mode and an UNDO mechanism using game-state history; final integration and correctness of these features are **not independently verified**.

## Technology

C, Linux terminal, GCC, Make, file I/O, two-dimensional arrays, modular programming and terminal input handling.
